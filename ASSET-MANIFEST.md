# Asset Manifest

No photographs have been downloaded or supplied. The shell here cannot fetch images from outside sites, so I did not claim any photos exist.

Each image slot works like this: `index.html` loads `assets/images/<name>.jpg`. If that file is missing, `script.js` automatically swaps in the matching `<name>.svg`, a decorative illustration generated for this project (sage / cream / gold shapes). The site therefore looks complete today, and real photos work by simply dropping a `.jpg` with the same name into `assets/images/` (the browser will log a harmless 404 for the missing `.jpg` until then).

## Sourcing guidance
- Best option: photographs of the real WELSTAND® premises, with the owner's permission.
- Otherwise use properly licensed stock photos (for example Unsplash or Pexels; check each licence) and keep the "illustrative image" notes, so stock is not presented as the actual premises or staff.
- Compress to roughly 150–300 KB each and keep the listed aspect ratios.
